# Linux secret-storage alpha19 sample 1

This directory contains the redacted machine-readable summary for the bounded
Debian 13 and Ubuntu 26.04 secret-storage qualification. It intentionally omits
SSH destinations, profile identifiers, control fingerprints, identity hashes,
credential hashes, private material, and raw journal output.

The artifact, test sequence, rejected diagnostics, limitations, and human
interpretation are documented in
[`../../linux-secret-storage-qualification-2026-09-12.md`](../../linux-secret-storage-qualification-2026-09-12.md).
