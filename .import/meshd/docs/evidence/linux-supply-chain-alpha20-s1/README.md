# Linux supply-chain alpha20 sample 1

`report.json` is the redacted, machine-readable summary of the exact-commit
package supply-chain qualification. It intentionally excludes host addresses,
temporary paths, package contents, and complete scanner output.

The immutable artifact identities and the limitations of this bounded result
are documented in
[`docs/linux-supply-chain-qualification-2026-09-12.md`](../../linux-supply-chain-qualification-2026-09-12.md).
